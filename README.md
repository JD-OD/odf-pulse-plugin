# ODF Pulse Plugin Marketplace

This repository contains the Open DealFlow Pulse plugin for Claude. Customers can add this marketplace to Claude to install the plugin and connect their Pulse account.

## Installation

To install the ODF Pulse plugin in Claude:

1. **Add the marketplace**
   - Go to Claude (claude.ai or your Claude app)
   - Navigate to **Customize → Plugins → Add → Add marketplace → Add from a repository**
   - Paste this repository URL: `https://github.com/JD-OD/odf-pulse-plugin`
   - Click to sync the marketplace

2. **Discover and install the plugin**
   - Go to **Discover**
   - Find **Odf Pulse**
   - Click to add the plugin

3. **Connect your Pulse account**
   - Go to the plugin page and select **Connectors → Connect**
   - Sign in to Pulse
   - Select your GoHighLevel sub-account
   - You're ready to use Claude with your Pulse data

## Requirements

- **Paid Claude plan** — Claude API, Claude Pro, or Claude Team
- **Active Pulse subscription** with the Claude connector enabled
- If "Connect" says the connector isn't enabled, contact support@opendealflow.com

## What's included

- **ODF Pulse skill** — Establishes safe, read-only access to your Pulse dashboards, deals, properties, buyers, and GoHighLevel CRM
- **MCP connector** — Routes Claude through the Pulse backend API to read your account data
